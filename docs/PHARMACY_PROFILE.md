# Pharmacy profile on receipts

Admins can update receipt branding and contact details from **Team → Pharmacy profile**.

## What can be changed

- Pharmacy name
- Phone number
- Email address
- Address/location
- Tax or registration number (optional, stored for future use)
- Receipt logo image

## Logo rules

- Allowed types: PNG, JPG, SVG, WEBP
- Maximum size: 1.5 MB
- Use **Use default logo** to return to the bundled METMMA logo assets.

## Where it appears

The saved profile is printed on every sales receipt (on-screen and print/PDF output). Empty fields are omitted automatically.
