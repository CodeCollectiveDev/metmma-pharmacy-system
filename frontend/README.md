# Frontend

The Vue 3 single-page application is built with Vite. Install dependencies and run it from the repository root:

```sh
npm ci --prefix frontend
npm run dev --prefix frontend
```

The development server is available at `http://localhost:5173` and proxies API requests to the local backend. See the [local setup guide](../docs/DEVELOPMENT_SETUP.md) for the database and backend steps, and the [deployment guide](../docs/DEPLOYMENT_VPS.md) for hosted frontend configuration.
